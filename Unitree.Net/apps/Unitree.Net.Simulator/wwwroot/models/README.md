# Robot meshes

GLB files converted from the visual meshes in
[`unitree_ros`](https://github.com/unitreerobotics/unitree_ros) by `tools/meshes/convert_meshes.py`.
Copyright (c) 2016-2022 HangZhou YuShu TECHNOLOGY CO.,LTD. ("Unitree Robotics"), BSD-3-Clause. See
`LICENSE.unitree_ros`, which must be distributed with these files.

The files are decimated and their colours replaced by surface roles. They are meant for display
only, not for collision checks or dynamics.
